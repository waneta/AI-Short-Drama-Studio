## 发现并修正的问题

1. 百炼生图预设落入通用 Images API，没有按千问原生请求/响应处理；新增本教程的千问原生适配。
2. 百炼视频预设缺少原生分流；新增万相 2.6 首帧/文生视频提交、查询、下载，使用选中视频接入的 Key。
3. 配图拼接四宫格指令、视频收集器优先打包人设等参考，均不适合万相单幅首帧；给百炼路线增加独立首帧路径。
4. Qwen3-TTS 先尝试另一条接口且缺 Key 时产生占位音；改为直接调用对应原生接口，缺 Key 明确失败。
5. ComfyUI 同时保存图片与视频时可能返回第一个预览图；改为按请求类型选取输出，并允许原生 Comfy 文生视频进入适配器。

## 尚未验收

- 尚未使用用户的 DeepSeek 或百炼 Key：真实账号权限、额度、地域、云端 CORS、真实模型的成片质量没有验收。
- 本次没有重跑本地 Z-Image 或 H3；本地图生视频首帧上传、映射、人物一致性仍需实际工作流测试。
- 没有生成四部故事的真实动态影片，没有验证口型同步或跨镜连续动作的成片质量。
- 未覆盖所有云平台、所有百炼模型、桌面打包、复杂时间线、长视频和其他原有功能。这不是“仓库没有 bug”的结论。
- 现有“万相 3.0 Prime”是独立旧路径，未纳入本教程的 2.6 首帧验收。教学操作应选择已保存的百炼接入名。
