# 迟到的约定

目标：40 秒，8 镜头，横屏 16:9，二维生活漫剧。

小满整理书桌时看到约定提醒，才意识到自己迟了。她抓起给阿林准备的小礼物，匆忙出门。车站入口，阿林正等在长椅边。小满赶到，把礼物递给他，低声道歉。阿林笑着接过，两人的紧张化成轻松。

1. 发现提醒：小满低头看手机后睁大眼睛；屏幕不生成文字。 字幕：约定时间，已经过了。。
2. 拿起礼物：双手缓慢拿起礼物盒，不改变丝带颜色。 字幕：无。
3. 准备出发：小满抱紧礼物，迈出一步离开卧室。 字幕：得快一点。。
4. 有人等待：阿林看向通道，轻轻调整站姿。 字幕：无。
5. 终于赶到：小满停步，轻轻喘气后抬头。 字幕：小满：对不起，我来晚了。。
6. 递出心意：小满将盒子向前递一点，阿林托住，动作缓慢。 字幕：无。
7. 接受道歉：阿林露出笑容，轻轻点头。 字幕：阿林：来了就好。。
8. 一起出发：两人并肩向入口走两步。 字幕：无。
