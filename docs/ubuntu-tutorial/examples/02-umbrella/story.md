# 雨中的伞

目标：25 秒，5 镜头，横屏 16:9，二维生活漫剧。

傍晚骤雨，小满抱着包站在雨棚边。阿林带着一把蓝色长柄伞走来，看见她的窘迫，停下脚步。他把伞举向两人之间，问她是否顺路。小满点头，两人一起走入雨中。

1. 被雨拦住：小满探出一只手接雨，随即收回；雨线连续落下。 字幕：雨怎么还不停。。
2. 来人停步：阿林向立柱方向转头，脚步停下。 字幕：无。
3. 邀请同行：阿林将伞向两人中间倾斜，身体不换位；小满抬眼看他。 字幕：阿林：一起走？。
4. 回应邀请：小满轻轻点头，微笑。 字幕：小满：谢谢。。
5. 走进雨里：两人并肩向前走两小步，阿林持伞，小满抱包，固定机位。 字幕：无。
