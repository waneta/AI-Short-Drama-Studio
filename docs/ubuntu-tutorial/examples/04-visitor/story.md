# 门后的来客

目标：60 秒，12 镜头，横屏 16:9，二维生活漫剧。

夜里，小满独自在客厅画画，忽然听见敲门声。她以为快递早已送完，走到门边问是谁。门外的人没有立刻回答，只传来纸袋窸窣声。小满犹豫后开门，发现妈妈拎着她爱吃的点心站在门外。妈妈说路过就来看看，她笑着把妈妈迎进屋。

1. 安静夜晚：小满低头缓慢画一笔。 字幕：无。
2. 敲门响起：听见两下敲门，小满抬头。 字幕：无。
3. 望向门口：小满缓慢转头看门。 字幕：这么晚，会是谁？。
4. 走到门边：小满向门靠近半步，停下。 字幕：无。
5. 隔门询问：小满微微侧头倾听，身体保持不动。 字幕：小满：谁呀？。
6. 纸袋线索：手指轻轻调整纸袋提绳。 字幕：无。
7. 犹豫片刻：她停顿一下，轻轻吸气。 字幕：无。
8. 开门一线：小满把门缓慢再推开一点，光线沿地面变宽。 字幕：无。
9. 妈妈来了：妈妈微笑，轻轻举起纸袋。 字幕：妈妈：路过，给你带点吃的。。
10. 放松下来：小满露出笑容，肩膀放松。 字幕：小满：快进来。。
11. 迎进屋里：妈妈向室内迈一步，小满侧身让路。 字幕：无。
12. 分享点心：妈妈把盘子轻轻推向小满，两人相视而笑。 字幕：原来，惊喜也会敲门。。
