# 第 09 章：剪辑、字幕、声音与最终 MP4

## 本章目标

将《忘带钥匙》的三个动态镜头剪成约 15 秒成片。先使用硬切，片段各 5 秒，再加入字幕与声音。

## 1. 先检查素材，再排时间线

1. 在“AI 视频”逐镜播放，确认有预期动作；下载三个 MP4 到本地备份。
2. 进入“视频剪辑”，点击“重建时间线”。确认三段顺序是回到门前、想起备用、找到钥匙。
3. 检查每段引用的是视频。缺视频时应用可能使用图片，导出成功也仍是预演，不能记作动态全流程成功。
4. 将各段入点设为有效画面起点，时长不超过可用素材。总长先按 15 秒核对；关掉复杂转场，速度先保持 1 倍。

先用播放器观察片段末尾是否有冻结、黑帧或主体消失。模型返回的时长不一定与计划完全相等，必要时缩短片段并调整字幕。

## 2. 加字幕

进入“字幕”，在 SRT 区点击“导入”，选择对应故事的 `captions.srt`。例如[忘带钥匙字幕](../examples/01-key/captions.srt)。字体选择本机可用的中文字体；先用底部白字、黑色描边和半透明底。

导入 SRT 后，以最终时间线逐条校对。如果剪掉了半秒，后面的字幕也要相应前移；“从分镜同步字幕”会重新生成时间码，可能覆盖手工调整。

## 3. 加声音

无对白第一版只用字幕。第二版在需要说话的镜头中选择 TTS，按[云端配音配置](03-cloud.md)生成并试听。每镜 5 秒的台词应足够短；声音太长时缩短台词或延长镜头，不要把尾字截掉。

`wan2.6-i2v-flash` 教程接入输出无声视频，环境声和对白需要后期补入。若换用带音频的模型，检查原声是否已经有人声，避免和 TTS 叠成两条对白。没有音乐素材时可以不加音乐，先把故事讲明白。

## 4. 导出与外部验收

1. 进入“导出”，确认不是空时间线；分辨率先用 1280×720，24 fps，开启烧录字幕。
2. 点击导出并等待编码，下载 MP4。
3. 用系统播放器打开，检查第一帧、每个切点和最后一帧，确认三个镜头都在。
4. 对照人物卡检查角色，试听对白完整性，观察字幕是否盖住钥匙或人物脸。
5. 使用 FFprobe 检查文件结构：

```bash
ffprobe -v error -show_entries format=duration:stream=codec_type,codec_name,width,height,r_frame_rate -of json your-film.mp4
```

元数据可以确认轨道与编码，不能判断故事是否流畅，也不能单独证明画面是动态生成的。后者需要逐镜播放与生成记录共同验收。

## 只有图片时的练习

使用[旧 3 秒静态视频](../examples/export-smoke.mp4)也能练习导入、字幕和导出。这只验证剪辑模块，不算云端视频模型通过。正式记录中请分开填写“静态预演”和“动态成片”。

## 交付清单

保存项目 JSON、所有原始 PNG/MP4/音频、最终 MP4、实际使用的 SRT、分镜表和[运行记录](../examples/cloud-run-record.md)。项目导出可能包含配置，分享前清理 Key。三镜动态片通过后，继续双人故事；四例完成后进入[本地迁移](10-local-migration.md)。
