# 第 02 章：导入人物、场景和三镜头项目

## 导入《忘带钥匙》

![工作台首页参考](../assets/home.webp)

1. 下载[项目 JSON](../examples/01-key/project.json)。
2. 在工作台进入[设置 → 系统](http://127.0.0.1:5173/#/settings/system)，点击“从文件导入”，选择 JSON。
3. 返回首页，打开“忘带钥匙 · 漫剧练习”。从经典步骤进入[分镜](http://127.0.0.1:5173/#/storyboard)。
4. 检查 3 个镜头：回到门前、想起备用、找到钥匙；每镜 5 秒。
5. 检查人物“小满”和场景“家门外走廊”；它们已经与镜头绑定，参考图片尚未生成。
6. 修改一个镜头的备注，刷新，再次打开项目，确认修改保留。

JSON 附有剧本、人物卡、场景卡、分镜、视频提示词和 SRT，时间线为空。生成素材后再重建时间线。它不会自动填写账号配置，也不会自动生成媒体。

## 自己写一个项目

先完成[云端配置](03-cloud.md)，再用 DeepSeek 将一句话扩写成完整短故事、拆成三镜。复制本例的结构，比较“一个镜头一个动作”是否做到了。第一次先使用教材 JSON，避免把 LLM 输出错误与视频接口错误混在一起。

## 保存与重复导入

项目与媒体在当前浏览器的 IndexedDB，配置在浏览器本地存储。换浏览器、无痕窗口、换访问端口，都可能看不到原来的项目。

同一个示例使用固定项目 ID，重复导入会更新原教材项目。保留自己的修改时先导出并备份原始媒体。设置页“导出所有项目”包含设置，可能带上 Key；分享前去掉 `settings`，只分享需要的项目。项目 JSON 不能代替媒体文件备份。

## 验收

三镜头、一个人物、一个场景全部出现；刷新后备注保留。随后进入[DeepSeek + 百炼配置](03-cloud.md)。
