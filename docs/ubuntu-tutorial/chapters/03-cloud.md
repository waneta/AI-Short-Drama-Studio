# 第 03 章：配置 DeepSeek 与阿里云百炼

## 本章目标与前提

完成一条文本响应、一张图片、一个动态视频和一句配音的独立检查，再运行三镜头项目。你已经有两家的 Key，分别填在自己的设置页面；不要写进教材、项目示例或截图。

下表以百炼北京地域为例。若 Key 来自新加坡等地域，地址必须切换为对应地域；不要把北京地址与海外 Key 混用。官方现有 DashScope 域名仍可用，业务空间专属域名请按自己的控制台填写。[地域与接口说明](https://help.aliyun.com/zh/model-studio/qwen-image-api)

## 1. 按能力分别保存接入

| 设置模块 | API 来源 | Base URL（北京示例） | 本教程模型 |
| --- | --- | --- | --- |
| 语言模型 | DeepSeek | `https://api.deepseek.com` | `deepseek-flash` |
| 生图 | 阿里云百炼 | `https://dashscope.aliyuncs.com/api/v1` | `qwen-image-2.0` |
| 视频 | 阿里云百炼 | `https://dashscope.aliyuncs.com/api/v1` | `wan2.6-i2v-flash` |
| 配音 | 阿里云百炼 | `https://dashscope.aliyuncs.com/api/v1` | `qwen3-tts-flash`，先试 `Cherry` |
| 视觉（选修） | 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3-vl-plus`，以账户支持为准 |

以上是本教程选用的接口组合，不是对所有最新模型的推荐。模型开通状态、地域与额度需要在控制台确认；不硬编码价格。DeepSeek 当前文档列出 `deepseek-flash`；旧教程或旧设置里的名字可能不同，按实际可用名称选择。[DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)

进入各设置模块，新建接入、选择 API 来源、填写地址与 Key、添加并选中模型名称。视频模块中的“模型 / 工作流名称”填 `wan2.6-i2v-flash`，将接入命名为“百炼 · 万相 2.6 首帧”。模型节点选择**已配置的视频接入**中的这个名字；“万相 3.0 Prime”是另一条旧代码路径，本教程不使用它。

百炼生图与视频使用原生协议，适配器保持“自动 / 默认”；不要改成自定义 HTTP 或 ComfyUI。原生生图使用 `input.messages`，视频使用异步任务；不能因为文本接口兼容 OpenAI，就把所有媒体接口都当成 `/images/generations`。

## 2. 先验证 DeepSeek

在剧本创作或助手中发送：

```text
请写一个15秒二维生活漫剧：主角小满，家门外走廊，发现没带钥匙，最后找到包里的备用钥匙。
只要3个镜头，每个5秒，每镜一个主要动作。
依次写景别、开场静帧、动作、台词、环境声；不要新增角色或地点。
```

检查是否真的得到三镜、每镜能在 5 秒内表现。不要让“翻包、找到钥匙、开门、进屋”挤在一个镜头里。将真实返回与教材分镜比较，保存模型名和耗时。导入现成 JSON 的成功不能替代这个检查。

## 3. 百炼生图：先资产，后分镜

在“AI 配图”先生成小满的人物设计图和走廊场景图，再生成第一镜。项目已带文字卡，尚无图片；应用可能自动补齐缺失的人物/场景图，因此点击一个镜头也可能触发多次生图。首轮逐项操作，先看结果再继续。

`qwen-image-2.0` 用同一模型完成文生图和参考图编辑；每次最多保留三张参考图。两人物加一个场景已经是三张，不要再额外塞入看板。`qwen-image-plus` 仅用于纯文生图，不能直接承担有参考图的人物一致性步骤。[千问文生图](https://help.aliyun.com/zh/model-studio/qwen-image-api)、[图像编辑](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)

选第一镜主图时检查：黄色外套、蓝包、蓝灰门、自然手部、一张完整画面。它将成为视频的首帧，不能是四宫格或角色四视图。

## 4. 百炼视频：单镜 5 秒

1. 在“AI 视频”选择保存的“百炼 · 万相 2.6 首帧”。
2. 使用第一镜的单幅配图；本路线不启用 H3 首尾帧链、数字人音频同步。
3. 使用示例中的完整视频提示词，目标 5 秒、720P。`wan2.6-i2v-flash` 在本适配中关闭内生音频，后期单独配音。
4. 提交后记录任务 ID；正常会经历排队、运行、下载。成功后播放并下载视频，刷新项目检查素材保留。
5. 如果超时，先用保存的 task_id 查询或重试恢复查询；不要立刻重复提交新任务。

原生万相接入会提交首帧 `img_url`、轮询 `/tasks/{id}` 并下载结果。本教程适配限制为 5、10、15 秒，以减少学习变量；这不是所有万相模型能力的完整枚举。[官方万相首帧接口](https://help.aliyun.com/zh/model-studio/legacy-image-to-video-api-reference/)

## 5. 配音最后加

先用字幕完成无对白版本，再配置 `qwen3-tts-flash` 与 `Cherry`，对一条短台词测试 TTS。听到自然语音后，再在镜头里选择 TTS 模式；人物卡的文字音色描述不等于已经配置了可用音色 ID。双人戏先逐句试听，再区分角色音色。

本分支会在缺 Key 时直接提示错误，不再把占位音当成真实配音。字幕与 TTS 是两项功能，不需要配音的镜头保持“无口播”。[Qwen-TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)

## 6. 浏览器连接问题

Web 版直接请求云端。现有 `/comfy-local` 代理只处理配置的 ComfyUI，并不代理 DeepSeek 或百炼。若开发者工具显示 CORS / Failed to fetch，先确认失败的是提交、轮询还是媒体下载；这是链路问题，改提示词不能解决。

遇到跨域阻断时，保留脱敏错误记录，使用经过配置的后端转发或受支持的运行方式再测试。不要把本教材写成“填 Key 必定能跑通”，也不要通过关闭浏览器安全机制来验收。本次未以真实 Key 验证当前环境的云端跨域行为。
